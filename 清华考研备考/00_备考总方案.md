## 一、先说你为什么不自信

你现在觉得没底气，原因是把「考清华」当成一座山，从山脚往上看，看不到顶。

但你的真实情况是：

- **数学不是零基础**。你大一考过年级前几名，这是硬证据。五年没碰只是生疏，不是不会。就像会游泳的人五年没下水，下去扑腾两下就回来了。
- **你有 AI 实战经验**。大多数考生只会做题，你已经在用 LLM 做产品。复试聊「大模型的实践理解」时，你是降维打击。
- **你不是一个人在搞**。你有 Claude Code 当学习工具——学数据结构时可以边写代码边问，学数学时可以随时让人用大白话解释概念。

这不是盲目鼓励。我说的是你确实有的优势。下面这份计划不依赖于「你很聪明」或者「你运气好」，只依赖于「你有没有按节奏执行」。

## 三、打工期（2026.07 — 2027.06）：铺路

**核心原则：这段不是拿来啃教材的，是拿来建立「学习势能」的。** 每天 1-2 小时的碎片时间强行啃教材，结果就是反复遗忘、反复挫败、最后放弃。

正确的做法是：**把最难的东西变简单、最抽象的东西变直觉。**

### 阶段 1-1：数学 — 重建直觉（每天 30-40 分钟）

**不要买任何考研教材。现在不是时候。**

按这个顺序看视频，建立视觉直觉：

| 顺序 | 内容                  | 资源                            | 时长估算 |
| ---- | --------------------- | ------------------------------- | -------- |
| 1    | 微积分本质（12 集）   | 3Blue1Brown, B站搜中文字幕      | 2 周     |
| 2    | 线性代数本质（15 集） | 同上                            | 3 周     |
| 3    | 概率论入门            | StatQuest (YouTube), 挑关键集看 | 2 周     |
| 4    | 神经网络与微积分      | 3Blue1Brown 深度学习系列        | 1 周     |

看视频的标准不是「看完」，而是**能用自己的话给别人讲一遍**。讲不出来就再看一遍。一节 15 分钟的视频看到能讲出来，比翻 50 页教材有用十倍。

**具体节奏：**

- 前 8 周：每天 30 分钟视频 + 10 分钟用 Obsidian/笔记软件写一句话总结（不是抄公式，是写「这个东西到底是干什么用的」）
- 之后：开始用 [Khan Academy](https://www.khanacademy.org) 做微积分基础题，每天 3-5 道，保持手感

### 阶段 1-2：数据结构 — 用代码学（碎片时间，每周 3-4 次）

**不要看邓俊辉的教材。现在也不是时候。**

你已经在用 AI 写代码，这就是最好的学习工具。每学一个数据结构，**直接写一个小项目**：

| 周次  | 写什么               | 练什么                  |
| ----- | -------------------- | ----------------------- |
| 1-2   | 逆波兰表达式计算器   | 栈                      |
| 3-4   | 简易浏览器前进/后退  | 栈                      |
| 5-6   | 文件目录大小统计器   | 树（递归遍历）          |
| 7-8   | Huffman 编码压缩工具 | 二叉树 + 贪心           |
| 9-10  | 最短路径可视化       | 图（BFS/Dijkstra）      |
| 11-12 | 关键词搜索高亮       | 串匹配（先 BF，后 KMP） |
| 13-14 | 排行榜系统           | 堆/优先队列             |
| 15-16 | 简易数据库索引       | 散列表 + 二分查找       |

每个项目的做法：

1. **先不要看教材，直接告诉 Claude Code 「我想用 Python 写一个 xxx，来解释一下原理」**
2. **理解了原理后自己写，卡住了再问**
3. **写完一个项目就推到 GitHub，一年后你有 8 个数据结构项目，复试直接拿出来**

注意：这些项目不用大，每个 100-300 行代码就够。目标是「理解数据结构长什么样」，不是做产品。

### 阶段 1-3：英语 — 每天渗透（每天 20 分钟）

英语一没法突击，词汇量 + 阅读速度必须靠长期积累。

| 事项       | 做法                                                                                       | 频率   |
| ---------- | ------------------------------------------------------------------------------------------ | ------ |
| 背单词     | [墨墨背单词](https://www.maimemo.com) 或 Anki，选考研英语词汇书，每天 20 个新词               | 每天   |
| 读 AI 前沿 | [Hugging Face Daily Papers](https://huggingface.co/papers) 或 arXiv AI 分类，每天挑一篇读摘要 | 每天   |
| 真题阅读   | 前 6 个月不碰真题，最后 3 个月再做                                                         | 冲刺期 |

**为什么读 AI 论文而不是考研阅读？** 因为 AI 论文跟你职业方向重叠，读完有价值感。考研阅读也是学术英文，词汇重合度高。两个目的合并成一个动作，省时间。

### 阶段 1-4：计组/OS/网络 — 暂缓

这三门零基础、偏理论，碎片时间啃不动。打工期不要碰。留到冲刺期集中突破。

| -------- | ---------------------- | ---- | ----------------------------------------------------- |
| 6-7 月   | **数据结构强化** | 200h | 王道考研 + 邓俊辉《数据结构》，每章课后题全部手写代码 |
| 8 月     | 计算机组成原理         | 150h | 王道考研 + 课后题，重点：Cache/流水线/数据表示        |

**核心策略：**

- 王道考研四本书是 826 的绝对核心，每一章后面的选择题、大题全部要做

- 真题太少（826 是自主命题，年份不多），所以王道 408 真题也要做，408 比 826 略简单但覆盖同类知识点

## 九、关于自信

上面这八千字，核心就一句话：

**你不需要每天都信心满满。你只需要在不想学的那天，依然做一点点——哪怕只看了 5 分钟视频、只写了 10 行代码。**

自信不是准备考研的前提条件。自信是你在这个过程中一点点赚到的——第一个项目跑通的时候、第一道积分题算对的时候、第一篇英文论文能直接读懂的时候。

你的优势不是凭空说的：

1. **你数学考过年级前几名。** 这不是「我觉得我数学还行」，这是一个客观事实。五年不碰只是锈，不是残。
2. **你做了 AI 产品。** 这不是培训班作业，是你自己从零做的。清华要的就是这种人，不是刷题机器。
3. **你知道怎么用 AI 学习。** 当别人还在靠看教材死磕的时候，你在用 Claude Code 边写代码边理解。你的学习效率是他们的 3 倍不止。
4. **你想清楚了才来的。** 你不是「反正考不上试试看」，你是认真研究了方向、分析了科目、制定了策略。这种清醒会让坚持变得容易很多。
