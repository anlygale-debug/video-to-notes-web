# 游戏功能优化方案

## 触发条件

仅在**游戏场景**下触发：

- 讨论装备系统、养成系统、战斗系统、PVE/PVP玩法、活动系统、商城、副本等游戏相关内容
- 讨论游戏需求文档 游戏优化文档 触发
- 涉及等级、品质、属性、掉落、消耗、打造、分解、鉴定、穿戴、强化等游戏机制
- "玩家反馈xxx不好用"、"数据表现xxx不好"、"调整一下xxx的数值"
- "这个玩法设计一下"、"新增一个副本"、"改一下掉落"、"加一个活动"
- "设计一下这个xxx系统"、"帮我把这个功能整理成方案"

**不触发**：通用产品需求文档、PRD、非游戏场景的优化方案。

## 工作流程

1. **理解需求**：先和用户确认功能范围、目标玩家、预期效果
2. **咨询细节**：如有不确定的地方先问清楚再动笔
3. **按模板输出**：根据功能复杂度调整各模块详略

## 输出模板

按以下 5 个模块撰写：

### 1. 设计目的
- 这个功能/优化要做什么
- 为什么要做（数据驱动或玩家反馈）
- 预期效果/目标指标

### 2. 系统入口
- 从哪里进入
- 解锁条件（如等级、前置任务）
- 入口位置描述

### 3. 系统说明
- 核心机制描述
- 关键规则和限制
- 数值公式（如有）：基础值 × 系数等
- 品质/等级/稀有度等分级说明（如适用）
- 消耗和产出（如适用）

### 4. 界面交互
- 界面布局描述
- 玩家操作流程（点击→跳转→查看→确认等）
- 交互细节（弹窗、tips、动画、按钮状态）
- 异常状态处理（空状态、不足提示）

### 5. 美术需求
- 需要哪些 UI 界面
- 需要哪些美术资源（图标、模型、特效）
- 数量和规格说明

## 输出规范

- 用简洁清晰的中文，避免大段描述
- 数值公式单独列出，格式如：`基础属性 = 阶级基础值 × 品质系数`
- 关键规则用列表形式呈现
- 保存为 Markdown 文件：`[功能名]-优化方案.md`

## 注意

- 输出内容结构和详略应适配功能复杂度
- 小优化可能不需要"美术需求"模块
