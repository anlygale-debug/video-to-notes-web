# G-Stack - 产品开发完整工作流

源自 Garry Tan (Y Combinator CEO)，包含 15 个专业子技能。

## 子技能速查

| 阶段 | 子技能 |
|------|--------|
| 构思 | office-hours, plan-ceo-review, plan-eng-review, plan-design-review |
| 开发 | review, investigate, design-consultation |
| 测试发布 | qa, qa-only, ship |
| 文档 | document-release, retro |
| 安全 | careful, freeze, guard, codex |

## 推荐工作流

1. `/gstack-office-hours` → 验证想法
2. `/gstack-plan-ceo-review` → CEO 视角评审
3. `/gstack-plan-eng-review` → 锁定技术架构
4. `/gstack-plan-design-review` → 设计师评审
5. `/gstack-review` → 代码审查
6. `/gstack-qa` → QA 测试
7. `/gstack-ship` → 发布
